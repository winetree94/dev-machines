# steam-devices role 추가 계획

Ubuntu-only apt 설치 role `steam-devices` 추가. `steam-devices` 는 Steam 컨트롤러용 udev rules 패키지(apt archive 제공, GUI 앱 아님).

## 변경 사항

### 1. `roles/steam-devices/tasks/main.yml` (신규)
`roles/xvfb/tasks/main.yml` 와 동일한 표준 8줄 `first_found` 디스패처:
```yaml
---
- name: Include OS-specific tasks
  ansible.builtin.include_tasks: "{{ item }}"
  with_first_found:
    - files:
        - "{{ ansible_facts['os_family'] | lower }}.yml"
        - default.yml
      skip: true
```

### 2. `roles/steam-devices/tasks/debian.yml` (신규)
```yaml
---
- name: Steam devices | Install Steam controller udev rules (apt)
  become: true
  ansible.builtin.apt:
    name: steam-devices
    state: present
```
`darwin.yml` / `windows.yml` 는 의도적으로 만들지 않음 (파일 없음 = 해당 OS에서 no-op).

### 3. `playbooks/setup.yml` (편집)
`Common tooling` play 의 `build tools` 섹션, `xvfb` (line 267-268) 뒤에 추가:
```yaml
    - role: steam-devices
      tags: [steam-devices]
```

### 4. `tests/validate_app_roles.yml` (편집)
`cli_roles` 테이블의 `xvfb` 엔트리 (line 416-417) 뒤에 추가:
```yaml
      - name: steam-devices
        debian: "name: steam-devices"
```
이 한 줄 추가로 디스패처 존재, `debian.yml` 존재, `darwin.yml`/`windows.yml` 부재, Common tooling play 배치, `name: steam-devices` 포함 등 파생 assert 가 자동 적용됨.

### 5. `AGENTS.md` (편집)
line 67 의 "The roles that install from apt" 목록에 `steam-devices` 추가.

## 검증
- `make verify` — syntax check + `tests/validate_*.yml` 전체 + yamllint + ansible-lint 실행하여 통과 확인.
- (선택) `make check ANSIBLE_ARGS="--limit ubuntu-dev --tags steam-devices"` 로 Ubuntu 대상 dry-run.
